## 现状基线

已经具备：多账户 IMAP/SMTP、统一收件箱、文件夹树与未读计数、分页/搜索、收藏视图（跨文件夹汇总星标）、星标/已读/归档/删除（删除带二次确认，可在本会话关闭）、富文本与附件、回复/转发、阅读器三视图（完整内容 / 简约文字 / 验证码）、演示模式、启动向导、管理员设置、偏好设置、凭据加密、HTML 清洗、CSP、Docker 与 CI。

已知缺口（按用户感知排序）：

1. 真实 IMAP 列表没有摘要，只有演示邮箱有 `preview`。
2. 统一收件箱只取每个账户第 1 页，且不显示分页，旧邮件不可达。
3. IMAP 报错会显示成「这里还没有邮件」，没有错误态与重试。
4. 关闭撰写窗口直接丢内容，没有草稿。
5. 只有「回复」，没有「全部回复」。
6. 附件下载每次重新拉整封邮件并重新解析。
7. 文件夹计数串行 `STATUS`，账户多/文件夹多时首屏慢。
8. 60 秒轮询全量刷新，没有 IMAP IDLE / 推送。
9. 没有批量操作、撤销、通知、签名、收件人补全、文件夹管理、附件预览、会话聚合。

## 批次 2：日常效率（M）

- [x] **2.1 草稿箱持久化**（M）
  - 本地草稿每 15 秒镜像到服务器：`POST /accounts/:id/drafts` 用 `APPEND` 写入 `\Drafts`（带 `\Draft` 标记），替换时先删除旧副本，避免草稿箱堆重复件；`DELETE /accounts/:id/drafts/:uid` 负责清理。没有 `UIDPLUS` 的服务器拿不到新 UID，自动只保留本地草稿。
  - 草稿箱里的邮件在阅读器显示「继续编辑」，打开撰写框时带回收件人、抄送、主题与正文；发送成功或丢弃时删除服务器副本，页脚提示「已同步到服务器草稿箱」。
- [x] **2.2 每账户签名**（S）
  - `accounts.signature`，撰写时插在引用上方，纯文本/HTML 两版。
- [x] **2.3 批量选择与操作**（M）
  - 复选框 + Shift 范围 + 全选本页；批量已读/未读、归档、删除；服务端按 `uids: number[]` 一次 IMAP 命令。
- [x] **2.4 撤销**（M）
  - 发送延迟 5 秒可撤销，倒计时显示在发送按钮与提示条，toast 也带「撤销」。
  - 归档/删除同样可撤销：服务端从 IMAP `COPYUID` 返回「源 UID → 目标 UID」映射，toast 的「撤销」把邮件从归档夹/废纸篓移回原文件夹；没有 UIDPLUS 的服务器不显示撤销入口。批量操作按账户分组一起撤回。
- [x] **2.5 收件人自动补全**（M）
  - `contacts` 表从已发送/来信积累，输入时下拉。
- [x] **2.9 已读标记与一键已读**（S）
  - 列表未读圆点/已读勾选、逐行切换、当前文件夹一键全部已读；打开中的邮件行有强调色左侧条与背景。
- [x] **2.6 未读角标与通知**（S）
  - `document.title` 未读数、动态 favicon；页面隐藏且授权时 `Notification`；设置页新增桌面通知开关与权限请求。
- [x] **2.7 快捷键扩展与帮助**（S）
  - `u/s/e/#/a/f/g i/x` 已接入；`?` 或列表标题栏键盘图标打开快捷键浮层。
- [x] **2.8 移动端手势**（M）
  - 左滑归档（无归档文件夹时删除）、右滑收藏、列表顶部下拉刷新；仅触摸设备触发。

- [x] **3.1 统一收件箱真分页**（M）
  - 新增 `GET /api/messages/unified`：服务端按页合并各账户 INBOX/收藏，返回真实总数与页码；列表分页对统一视图生效。
  - 有账户读取失败时列表顶部显示「N 个账户暂时无法读取」，不再静默少几封。
- [x] **3.2 列表摘要**（M）
  - 列表 FETCH 附带前 4KB 源，轻量解析首个 text part（quoted-printable / base64 / multipart / HTML），生成 180 字摘要；详情解析不复用该路径。
- [x] **3.3 文件夹计数优化**（M）
  - 限流并发 + 只算 INBOX/当前文件夹 + SQLite TTL 缓存。
- [ ] **3.4 IMAP IDLE + SSE**（L）
  - 独立 IDLE 连接，`/api/events` 推未读变化；前端只 invalidate 对应 query；反向代理关闭缓冲。
- [ ] **3.5 本地缓存 + FTS5**（L，分阶段）
  - 先列表、再正文、最后全文搜索；解决离线阅读与跨账户搜索。
- [x] **3.6 附件流式上传/下载**（M）
  - 上传走 multer 磁盘存储 + `path` 交给 MailComposer 流式组装；下载把 IMAP 整封流按 MIME 解析，附件直接写盘并进 LRU 磁盘缓存，内存只留正文与元数据。
  - 待补：前端上传进度条（当前只有发送中的按钮态）。
- [x] **3.7 文件夹管理**（M）
  - 侧栏新建/重命名/删除自定义文件夹、清空废纸篓；IMAP 用 `CREATE`/`RENAME`/`DELETE`/`CLOSE`，演示邮箱同步支持。
- [ ] **3.8 会话聚合**（L）
  - `References`/`In-Reply-To` + 规范化主题；列表显示「N 封」。
