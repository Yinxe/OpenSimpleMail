## 现状基线

已经具备：多账户 IMAP/SMTP、统一收件箱、文件夹树与未读计数、分页/搜索、收藏视图（跨文件夹汇总星标）、星标/已读/归档/删除（删除带二次确认，可在本会话关闭）、富文本与附件、回复/转发、阅读器三视图（完整内容 / 简约文字 / 验证码）、演示模式、启动向导、管理员设置、偏好设置、凭据加密、HTML 清洗、CSP、Docker 与 CI。

已知缺口（按用户感知排序）：

1. 真实 IMAP 列表没有摘要，只有演示邮箱有 `preview`。
2. 统一收件箱只取每个账户第 1 页，且不显示分页，旧邮件不可达。
3. IMAP 报错会显示成「这里还没有邮件」，没有错误态与重试。
4. 关闭撰写窗口直接丢内容，没有草稿。
5. 只有「回复」，没有「全部回复」。
6. 附件下载每次重新拉整封邮件并重新解析。
7. 文件夹计数串行 `STATUS`，账户多/文件夹多时首屏慢。
8. 60 秒轮询全量刷新，没有 IMAP IDLE / 推送。
9. 没有批量操作、撤销、通知、签名、收件人补全、文件夹管理、附件预览、会话聚合。

## 批次 2：日常效率（M）

- [x] **2.1 草稿箱持久化**（M）
  - 本地草稿每 15 秒镜像到服务器：`POST /accounts/:id/drafts` 用 `APPEND` 写入 `\Drafts`（带 `\Draft` 标记），替换时先删除旧副本，避免草稿箱堆重复件；`DELETE /accounts/:id/drafts/:uid` 负责清理。没有 `UIDPLUS` 的服务器拿不到新 UID，自动只保留本地草稿。
  - 草稿箱里的邮件在阅读器显示「继续编辑」，打开撰写框时带回收件人、抄送、主题与正文；发送成功或丢弃时删除服务器副本，页脚提示「已同步到服务器草稿箱」。
- [x] **2.2 每账户签名**（S）
  - `accounts.signature`，撰写时插在引用上方，纯文本/HTML 两版。
- [x] **2.3 批量选择与操作**（M）
  - 复选框 + Shift 范围 + 全选本页；批量已读/未读、归档、删除；服务端按 `uids: number[]` 一次 IMAP 命令。
- [x] **2.4 撤销**（M）
  - 发送延迟 5 秒可撤销，倒计时显示在发送按钮与提示条，toast 也带「撤销」。
  - 归档/删除同样可撤销：服务端从 IMAP `COPYUID` 返回「源 UID → 目标 UID」映射，toast 的「撤销」把邮件从归档夹/废纸篓移回原文件夹；没有 UIDPLUS 的服务器不显示撤销入口。批量操作按账户分组一起撤回。
- [x] **2.5 收件人自动补全**（M）

- [x] **2.9 已读标记与一键已读**（S）

- [x] **2.6 未读角标与通知**（S）
