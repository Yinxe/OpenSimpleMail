# OpenSimpleMail 界面重设计 · 方向探索

## 现状诊断（1440×900，自动检查 + 截图）

- 收件箱页 41 处文字对比度低于 4.5:1；侧栏「写邮件」4.24、次级文字 3.61。
- 列表预览 11.5px、日期 9.5px、文件夹计数 10.5px；发件人与主题同为 13px/600，扫读时不知道先看谁。
- 每行常驻星标 + 删除两个低对比图标；未读只是一个 4px 圆点。
- 三栏比例 240 / 392 / 808，右栏 56% 面积在未选中时完全空置。
- 登录页大标题把「方。」甩成孤行；深色品牌区占 52%，压过真正的登录任务；眉标、网格、光晕、版本号等装饰件偏模板。

## 三个方向

三版共用同一份示例邮件、同一视口（1440×900）、同一封阅读中的邮件（王小明 / Q4 规划文档）。

### A. 台账 / Ledger

安静来自精确。全亮界面，去掉深色侧栏；列表像台账：发件人降为次级，主题成为每行的锚点，未读用左侧方块而不是圆点；彩色只留给状态。主色墨蓝 `#2F5D8C`。

### B. 信笺 / Letterpress

安静来自材质。奶油纸底、墨绿主色、浅色侧栏；列表每封邮件是一枚带首字母印章的「信」，阅读区是一张 632px 宽的纸，顶部信头、发件人/收件人字段表，衬线标题与正文。主色墨绿 `#1F5A4C`。

### C. 夜读台 / Night Desk

安静来自光。默认深色，64px 图标轨 + 420px 列表 + 暗色桌面上的暖白信纸；等宽数字做时间，琥珀色只用于未读、星标和写邮件。主色琥珀 `#E0A458`。

### D. 现版精修 / Refined（在 A/B 之后补充）

用户反馈 A/B「不如现在的」。原因是 A/B 把现版最值钱的东西换掉了：深色侧栏的明暗对比、暖纸底、陶土色、衬线标题。D 保留这四项资产，只修可用性问题：字号与行高、次级文字对比度、发件人/主题层级、每行常驻图标、列表裁切、阅读区工具条。D 不是第四种风格，是「现版 + 结构修正」。
